# Ayush's learning shelf

Course projects, systems implementations, and experiments by [Ayush Biswas (@veryshyjelly)](https://github.com/veryshyjelly).

I learn by building the pieces: parsers, protocols, interpreters, and the tools around them. This organization collects that work in one place.
